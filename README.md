# 幻境游乐场 · 命运试炼馆

一款运行在浏览器里的虚拟游艺合集（虚构娱乐，无真实货币、无真实赌博机制），包含：

- 年龄声明与免责提示（未满 18 周岁禁止进入）
- 多存档系统：命名、删除、四种难度（轻松 / 正常 / 困难 / 作弊）
- 时间与租金：每完成一局推进一天，正常 / 困难每周收取馆租，交不起则档案落幕并只能查看总结
- 作弊模式专属菜单：可给自己任意金币
- 六个小游戏：
  1. 拾光清扫 —— 四色垃圾拖拽分类，放对一件 +2 金币
  2. 二十一点 —— 要牌 / 停牌 / 双倍，自然二十一点 2.5 倍
  3. 投票猜拳 —— 神秘木箱随机卡组，三张牌逐轮对决
  4. 生死剑 —— 六孔拖拽投入金币，三剑飞射，剑刃 / 剑柄 ×20 结算
  5. 生死转盘 —— 装弹入暗箱、红心排列、随机取枪按匹配差开枪
  6. 命运塔罗 —— 13 张塔罗 + 大王，正逆随机轮流翻牌
- 卡牌皮肤商城：7 档皮肤，越贵越华丽，装备后替换所有牌类卡背
- 成就系统：18 项成就，自动解锁并发放金币

## 运行方式

需要 Node.js 20+（本项目也支持 Codex 桌面环境自带的 Node）。

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173`。

也可以直接双击 `启动游戏.cmd`（会优先使用本机 pnpm，找不到时回退到 Codex 内置 Node）。

生产构建：

```bash
pnpm build
pnpm preview
```

## 存档说明

- 存档保存在浏览器 localStorage 中，键名 `mirage-playground-saves-v1`
- 删除存档后无法恢复
- 「作弊」难度按「轻松」规则开局（无租金），但主厅会出现作弊菜单
- 正常 / 困难难度：每周（第 8、15、22…天）结算馆租；金币不足则档案「命运落幕」，只能查看总结或删除

## 技术栈

- Phaser 3 + TypeScript + Vite
- DOM 负责菜单 / 卡牌 / HUD，Phaser 负责粒子、飞剑、开火等特效
- 全部视觉为程序化绘制（渐变、CSS 纹理、emoji 素材），无需外部美术资源
